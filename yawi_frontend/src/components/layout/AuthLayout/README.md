# AuthLayout

Layout minimalista para páginas de autenticación (`/login`, `/register`).

## Diferencia con AppLayout

- **Sin distracciones:** No incluye `Navbar` con menú ni `Footer` completo.
- **Header esencial:** Solo muestra el logo centrado/enlazado a `/` y un conmutador discreto de idioma (ES/EN).
- **Contenido centrado:** Área principal flexbox que centra los formularios en pantalla tanto horizontal como verticalmente.

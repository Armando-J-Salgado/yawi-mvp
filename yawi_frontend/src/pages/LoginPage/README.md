# Página de Inicio de Sesión (`/login`)

Página de inicio de sesión que monta el formulario `LoginForm` dentro de `AuthLayout`.

## Características

- Encabezado con título y subtítulo traducidos desde el namespace `auth`.
- Validación con seguridad por oscuridad (sin mensajes por campo, error genérico en toast).
- Enlace directo a `/register` para usuarios que no tienen cuenta.

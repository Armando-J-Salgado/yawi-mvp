# Página de Registro (`/register`)

Página de registro de clientes que monta el formulario `RegisterForm` de dos pasos dentro de `AuthLayout`.

## Características

- Registro en dos fases: Credenciales (Step 1) y Datos Personales (Step 2).
- Selector de países traducido automáticamente según el idioma de la aplicación.
- Enlace directo a `/login` para usuarios que ya poseen una cuenta.
